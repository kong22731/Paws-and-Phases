ภาค 7ควบคุมด้วยมือผ่านกล้อง (HandControl)

js/systems/HandControl.js (542 บรรทัด) ทำให้เล่นเกมด้วยมือผ่านเว็บแคมได้ เหมือนแตะจอมือถือ: มี "ถุงมือ" เล็กๆ บนจอที่ลอยตามมือ และท่ามือต่างๆ แทนการคลิก

กล้อง→MediaPipe หาจุดบนมือ 21 จุด→classify แยกท่า→feed: ขยับถุงมือ→ส่ง mouse event ปลอมเข้าปุ่ม
หัวใจของระบบ: การกดของมือถูกส่งเป็น mouse/pointer event จริงเข้าไปที่ element ใต้ถุงมือ เกมและแผงแชทจึงคิดว่าเป็นเมาส์ ปุ่มเดิมทุกปุ่มใช้ได้โดยไม่ต้องแก้โค้ดของปุ่มเลย ภาพกล้องประมวลผลในเครื่องเท่านั้น ไม่ส่งไปที่ใด

จุดบนมือ 21 จุดของ MediaPipe

0 = ข้อมือ, 1–4 = นิ้วโป้ง (โคน → ปลาย), 5–8 = นิ้วชี้, 9–12 = นิ้วกลาง, 13–16 = นิ้วนาง, 17–20 = นิ้วก้อย ปลายนิ้วคือ 4, 8, 12, 16, 20 พิกัดอยู่ในช่วง 0–1 ตามขนาดภาพ

classify(P): แยกท่ามือ

ใช้ ระยะห่างจากข้อมือ แทนการดูแกนขึ้นลง จึงจับท่าได้แม้มือเอียงหรือหมุน

  1. size = ระยะข้อมือถึงโคนนิ้วกลาง (ขนาดมือ ใช้ปรับเกณฑ์ให้ไม่ขึ้นกับว่ามือใกล้หรือไกลกล้อง)
  2. นิ้วชี้ กลาง นาง ก้อย: อัตราส่วน r = (ปลายนิ้ว↔ข้อมือ) ÷ (ข้อกลางนิ้ว↔ข้อมือ) ถ้านิ้วเหยียด ปลายนิ้วอยู่ไกลกว่าข้อ r > 1.15 = เหยียด ถ้างอ ปลายนิ้วพับกลับเข้ามา r < 1.0 = งอ ระหว่างนั้น = ไม่แน่ใจ
  3. นับจำนวนนิ้วเหยียด (ext) และนิ้วงอ (fold)
  4. นิ้วโป้ง: thumbFar = ระยะปลายนิ้วโป้งถึงโคนนิ้วชี้ ÷ ขนาดมือ thumbUp = โป้งกางออก และจุด 4 อยู่สูงกว่า 3 สูงกว่า 2 (ชี้ขึ้น) และสูงกว่าโคนนิ้วชี้พอสมควร
  5. ตัดสิน:
    • งอครบ 4 นิ้ว + โป้งชี้ขึ้น → thumb 👍
    • งอครบ 4 นิ้ว + โป้งแนบ (thumbFar < 0.75) → fist ✊
    • ชี้ + กลางเหยียด, นาง + ก้อยงอ → peace ✌️
    • เหยียด 3 นิ้วขึ้นไป → open ✋
    • นอกนั้น → other

ออบเจ็กต์ Hand: สถานะและระบบ event

สถานะหลัก: active (เปิดอยู่), status (off / loading / nohand / tracking / error), gesture (ท่าที่นิ่งแล้ว), x, y (ตำแหน่งถุงมือบนหน้าจอ), visible, pressed (กำลังกด)

  • on(ev, fn) สมัครรับเหตุการณ์ (เก็บฟังก์ชันในรายการของชื่อนั้น), off ยกเลิก, emit(ev, ...) เรียกทุกฟังก์ชันที่สมัครไว้ ครอบ try/catch ไว้ ฟังก์ชันหนึ่งพังไม่ทำให้ตัวอื่นไม่ถูกเรียก
  • เหตุการณ์ที่ส่ง: change (เปิด/ปิด), frame (ทุกเฟรมกล้อง), gesture, peace, thumb, press, release
  • prof() คืนโปรไฟล์ความไวตามการตั้งค่า

start(): เปิดกล้อง (async)

  1. เปิดอยู่แล้วคืน true สร้าง DOM (ถุงมือและแผงกล้อง) ตั้งสถานะ loading แสดงแผง
  2. ไม่มี getUserMedia (เบราว์เซอร์ไม่รองรับ หรือไม่ใช่ https/localhost) → โยนข้อผิดพลาด
  3. await getUserMedia(...) ขอใช้กล้องหน้า 640×480 ไม่ขอไมค์ เบราว์เซอร์ถามสิทธิ์ผู้ใช้ตรงนี้
  4. ถ้าระหว่างรอผู้เล่นปิดไปแล้ว (!this.active) หยุดกล้องและคืน false
  5. ต่อภาพกล้องเข้า <video> แล้วเล่น โหลดโมเดลถ้ายังไม่เคยโหลด (ครั้งต่อไปใช้ของเดิม)
  6. สถานะ nohand ตั้ง PetGame.inputMode = 'hand' เริ่มลูป แจ้ง change ถ้ายังไม่เคยดูหน้าสอนเล่น เปิดให้ดู
  7. ผิดพลาดตรงไหน: ถ้าข้อความมีคำว่า denied/NotAllowed บอกว่าไม่ได้รับอนุญาต ไม่งั้นบอกข้อความผิดพลาด ปิดทุกอย่างแล้วคืน false

stop(), toggle(), stopStream()

stop ปิดสถานะ กลับเป็นโหมดเมาส์ ยกเลิกลูป (cancelAnimationFrame) ปิดกล้อง ปล่อยการกดค้าง ล้างสถานะ ปิดหน้าสอน ซ่อนแผง และแจ้ง change ส่วน stopStream หยุดทุก track ของกล้อง (ไฟกล้องดับ) toggle สลับเปิด/ปิด

loadModel()

  1. import() แบบไดนามิก โหลดไลบรารีจาก CDN เฉพาะตอนเปิดใช้ครั้งแรก (ผู้ที่ไม่ใช้มือไม่ต้องโหลดไฟล์ขนาดใหญ่)
  2. FilesetResolver.forVisionTasks โหลดไฟล์ WebAssembly ที่ใช้ประมวลผล
  3. สร้าง HandLandmarker: โหมด VIDEO ตรวจ 1 มือ ความมั่นใจขั้นต่ำ 0.6/0.6/0.5
  4. ลองใช้ GPU ก่อน (เร็วกว่า) ถ้าไม่ได้ใช้ CPU

loop()

เรียกตัวเองทุกเฟรมด้วย requestAnimationFrame ข้ามถ้าวิดีโอยังไม่พร้อมหรือยังเป็นเฟรมเดิม (เวลาวิดีโอไม่เปลี่ยน) ส่งเฟรมให้โมเดลหามือ (detectForVideo) ได้จุดของมือแรก แล้ววาดโครงมือบนภาพกล้องและส่งต่อให้ feed

reset() ซ่อนถุงมือ ล้างท่า ล้างการชี้ค้าง และอัปเดตไอคอน

feed(lm, now): แปลงจุดบนมือเป็นถุงมือและท่า

แยกออกจาก loop เพื่อทดสอบได้โดยป้อนจุดจำลองแทนกล้องจริง

  1. ไม่เห็นมือ: ถ้าถุงมือแสดงอยู่และหายเกิน 0.35 วินาที ปล่อยการกด ล้างสถานะ แจ้ง nohand แล้วจบ
  2. จำเวลาที่เห็นล่าสุด สถานะ tracking
  3. กลับด้านแบบกระจก: x = 1 − x (ยกมือขวา ถุงมือไปทางขวาของจอ เหมือนส่องกระจก)
  4. ทำให้ท่านิ่ง: ท่าที่จำแนกได้เป็นแค่ "ผู้สมัคร" (candidate) ถ้าต่างจากเดิมเริ่มนับใหม่ จะยอมรับเป็นท่าจริงเมื่อเห็นติดกันอย่างน้อย 2 เฟรม และ ✌️/👍 ต้องค้างครบ 0.45 วินาที กันท่ากระพริบเปลี่ยนไปมา
  5. ตำแหน่ง = กลางฝ่ามือ (เฉลี่ยจุด 0, 5, 9, 13, 17) จุดเหล่านี้แทบไม่ขยับเมื่อกำหรือแบมือ ถุงมือจึงไม่กระโดดตอนเปลี่ยนท่า
  6. แปลงเป็นพิกเซล: ตัดขอบภาพตาม margin แล้วยืดส่วนกลางให้เต็มจอ (mx − margin) / (1 − 2·margin) บีบเป็น 0–1 แล้วคูณขนาดหน้าต่าง = ขยับมือแค่ช่วงกลางภาพก็ไปได้ทั่วจอ
  7. ถ้าเพิ่งปรากฏ วางตรงเป้าทันที
  8. ทำให้นุ่ม (smoothing): ถ้าไม่ได้อยู่ช่วงหยุดนิ่ง และห่างจากเป้าเกิน 1.2 พิกเซล ขยับเข้าหาเป้าเป็นสัดส่วน a = ความไว + ระยะ/500 (ไกลมากขยับเร็ว ใกล้ขยับช้า ไม่เกิน 0.75) ถ้ากำลังเปลี่ยนท่า ลดเหลือ 40% การขยับทีละสัดส่วนแบบนี้ช่วยกรองอาการมือสั่น
  9. วางถุงมือ ส่ง mousemove และถ้ากำอยู่แล้วขยับเกิน 14 พิกเซล เข้าสู่การลาก (ถุงมือเรืองแสง)
  10. อัปเดตการชี้ค้าง และแจ้ง frame พร้อมท่าปัจจุบัน

setGesture(g, now)

เมื่อท่าเปลี่ยนจริง: กำมือ → ตั้งเวลาหยุดนิ่ง 0.15 วินาทีแล้วกด (press) ท่าอื่นขณะกดอยู่ → ปล่อย ✌️/👍 → ส่งเหตุการณ์ peace/thumb สลับรูปถุงมือ (คลาส fist) และอัปเดตไอคอน

การชี้ค้าง (Dwell Click)

  1. updateDwell ปิดการชี้ค้างถ้า: ปิดในการตั้งค่า กำลังกด หรือทำท่ากำ/✌️/👍 อยู่
  2. หาสิ่งที่กดได้ใต้ถุงมือ (clickableAt)
  3. ถ้าเพิ่งกดไปและล็อกอยู่ ปลดล็อกเมื่อเลื่อนออกเกิน 40 พิกเซลหรือออกจากปุ่ม ถ้ายังล็อกหรือไม่มีปุ่ม รีเซ็ตวงแหวน
  4. ถ้าเป็นปุ่มใหม่หรือขยับเกิน 28 พิกเซล เริ่มนับเวลาใหม่
  5. ความคืบหน้า = เวลาที่ค้าง ÷ เวลาที่ต้องใช้ แสดงเป็นวงแหวน ครบ 1 → ล็อกตำแหน่ง ถ้าเป็นปุ่ม HTML เล่นเสียง toggle (ปุ่มในเกมมีเสียงของตัวเองอยู่แล้ว) แล้วแตะ
  • setDwell(p) แสดงวงแหวนเมื่อ p > 4% วงแหวนวาดด้วยเทคนิค stroke-dasharray/stroke-dashoffset: ตั้งเส้นประยาวเท่าเส้นรอบวง แล้วเลื่อน offset จากเต็มไปถึง 0 เส้นจะค่อยๆ ปรากฏรอบวง
  • clickableAt() หา element ใต้จุดด้วย document.elementFromPoint ถ้าเป็น canvas ของเกมไปถาม Phaser ถ้าเป็น HTML หา button / input / ลิงก์ที่ใกล้ที่สุดด้วย closest
  • phaserButtonAt() วนฉากที่ทำงานอยู่จากบนสุดลงล่าง ถาม hitTestPointer ว่าเมาส์โดนวัตถุอะไร เรียงตามความลึก แล้วนับเฉพาะวัตถุบนสุดที่เป็น "ปุ่ม" คือมี input.cursor (ตั้ง useHandCursor ไว้) และไม่ได้ติด noDwell ตัวสัตว์ แผงกันกดทะลุ และพื้นมืดจึงไม่ถูกกดโดยไม่ตั้งใจ

ส่ง event เหมือนเมาส์จริง

เมธอดการทำงาน
targetAt()element ใต้ถุงมือ (ไม่มีใช้ body)
fire(type, target)สร้างข้อมูล event (ตำแหน่ง ปุ่มซ้าย สถานะปุ่มกด) ส่ง PointerEvent (Phaser ใช้) แล้วตามด้วย MouseEvent (HTML ใช้) ทั้ง 2 แบบ bubbles = ส่งต่อขึ้นไปยัง element แม่
pointerMove()ไฮไลต์ปุ่ม HTML ที่อยู่ใต้ถุงมือ (คลาส hand-hover แทน hover ของเมาส์) แล้วส่ง mousemove
press()บันทึกจุดและ element ที่กด ส่ง mousedown ถ้าเป็นช่องพิมพ์ให้โฟกัส ถุงมือยุบ และวงคลื่นกระจาย (ripple)
releasePress()ส่ง mouseup ถ้ากดและปล่อยบนปุ่ม HTML ตัวเดียวกัน เรียก click() (ปุ่ม HTML ทำงานด้วย click ส่วน canvas ใช้แค่ down/up) ล้างสถานะกดและลาก
tap()กดแล้วปล่อยหลัง 70 มิลลิวินาที (ใช้กับการชี้ค้าง)

buildDom(): สร้างถุงมือและแผงกล้อง

  1. สร้างครั้งเดียว ถุงมือ #hand-glove มีวงแหวน รูปแบมือ และรูปกำมือ (CSS เลือกแสดงตามคลาส) ส่งค่าจุดอ้างอิงและขนาดเป็นตัวแปร CSS ต่อท้าย body
  2. เตรียมวงแหวนให้ว่าง (offset = ความยาวเต็ม)
  3. แผงกล้อง #cam-panel: แถบสถานะ (จุดสี ข้อความ ปุ่ม ? 👁 ✕) แถวไอคอนท่ามือ กล่องวิดีโอ + canvas สำหรับวาดโครงมือ และหมายเหตุความเป็นส่วนตัว แทรกไว้ใต้หัวแผงแชท
  4. จอเล็ก (สูงไม่ถึง 640 หรือกว้างไม่ถึง 760) ซ่อนภาพกล้องตั้งแต่แรก ถ้าผู้เล่นเคยตั้งไว้ใช้ค่าที่ตั้ง
  5. ผูกปุ่ม: 👁 ซ่อน/แสดงภาพกล้อง (จำในการตั้งค่า), ✕ ปิดระบบมือ, ? เปิดหน้าสอนเล่น

drawPreview(lm)ล้าง canvas ถ้าเห็นมือและไม่ได้ซ่อนภาพ วาดเส้นกระดูกตาม BONES (กลับซ้ายขวาให้ตรงกับวิดีโอที่ CSS กลับด้านไว้ สีเหลืองตอนกำ สีฟ้าตอนปกติ) และจุดทั้ง 21 จุด
gamePoint(game)แปลงตำแหน่งถุงมือบนหน้าจอเป็นพิกัดในเกม 960×600 จากขนาดจริงของ canvas (เกมถูกย่อขยายตามหน้าต่าง) ถ้าอยู่นอกเกมคืน null GameScene ใช้เช็กว่ามืออยู่บนตัวสัตว์ไหม

หน้าสอนเล่น 3 ขั้น

  1. showTutorial() สร้างกล่อง #hand-tutorial ในพื้นที่เกม เริ่มขั้น 0 และสมัครรับเหตุการณ์:
    • tutFrame (ขั้น 1) สะสมระยะที่ถุงมือเคลื่อนที่ อัปเดตแถบ (ทุก 6 พิกเซล = 1%) ครบ 600 พิกเซลไปขั้นถัดไป
    • tutPose (ขั้น 3) ทำ ✌️ หรือ 👍 แล้วจบ
  2. renderTutorial() วาดการ์ดตามขั้น: ขั้น 1 Move (แถบความคืบหน้า), ขั้น 2 Tap (ปุ่ม "Tap me!" กดด้วยการกำมือหรือชี้ค้าง เปลี่ยนเป็น "Nice! 🎉" แล้วไปต่อ), ขั้น 3 Say hi & praise (สรุปทุกท่า + ปุ่ม "Let's play!") มีปุ่ม Skip และจุดบอกขั้น
  3. nextTutorial() ไปขั้นถัดไป เกินขั้นสุดท้ายจบ
  4. finishTutorial() บันทึกว่าดูแล้ว (ครั้งหน้าไม่ขึ้นเอง) แล้วปิด
  5. closeTutorial() ยกเลิกการสมัครเหตุการณ์และลบกล่อง
