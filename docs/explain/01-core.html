  • <meta name="viewport" ...> ให้หน้าเว็บกว้างเท่าจอจริงบนมือถือ/แท็บเล็ต ไม่ย่อเป็นหน้าเดสก์ท็อป
  • <title>Paws &amp; Phases</title> ชื่อที่ขึ้นบนแท็บเบราว์เซอร์ (&amp; คือวิธีเขียนเครื่องหมาย & ใน HTML)
  • preconnect 2 บรรทัด สั่งให้เบราว์เซอร์เปิดการเชื่อมต่อกับเซิร์ฟเวอร์ Google Fonts ล่วงหน้า ฟอนต์จะโหลดเร็วขึ้น
  • ลิงก์ fonts.googleapis.com/css2?family=... โหลดฟอนต์ 4 ตระกูล: Amarante (หัวข้อ), Inter ตัวเอียงหนา (ตัวเลข), Kanit (ภาษาไทย) และ Sniglet (ตัวหนังสือหลักของเกม)

รอฟอนต์ก่อนเริ่ม

ข้อความใน canvas ถูก "วาด" ครั้งเดียวตอนสร้าง ถ้าฟอนต์ยังโหลดไม่เสร็จ ตัวหนังสือจะออกมาเป็นฟอนต์สำรองและไม่เปลี่ยนตามทีหลัง โค้ดจึงรอก่อน:

  • document.fonts.load(f) สั่งโหลดฟอนต์แต่ละแบบ (Kanit 3 น้ำหนัก, Sniglet ปกติ/หนา, Amarante, Inter เอียงหนา) ได้ Promise กลับมา
  • Promise.all รอจนครบทุกฟอนต์ ถ้าเบราว์เซอร์ไม่มี document.fonts ก็ข้ามไป (Promise.resolve())
  • Promise.race([fontReady, รอ 2 วินาที]) แข่งกันว่าอะไรเสร็จก่อน: ถ้าเน็ตช้าจะไม่รอเกิน 2 วินาที
  • .then(boot, boot) ไม่ว่าสำเร็จหรือผิดพลาดก็เรียก boot เกมจึงเปิดได้เสมอ

js/systems/Settings.js การตั้งค่าผู้เล่น · 30 บรรทัด

เก็บการตั้งค่าที่ไม่ผูกกับสัตว์ตัวใด (ความยาววัน เสียง การควบคุมด้วยมือ) ไว้ใน localStorage ของเบราว์เซอร์ คีย์ lovelyPetEvolutions.settings แยกจากไฟล์เซฟสัตว์

  1. DEFAULTS ค่าเริ่มต้น: dayMinutes 3, music true, sfx true, handSensitivity 'normal', dwell true, handTutorialDone false

  3. let s = Object.assign({}, DEFAULTS); คัดลอกค่าเริ่มต้นมาเป็นชุดที่ใช้งาน
  4. JSON.parse(localStorage.getItem(KEY) || '{}') อ่านค่าที่เคยบันทึก (ถ้าไม่มีใช้ '{}') แล้ว Object.assign ทับลงไป ค่าที่ไม่เคยบันทึกจึงยังเป็นค่าเริ่มต้น ครอบด้วย try/catch กันข้อมูลเสียทำให้เกมพัง
  5. ถ้า dayMinutes ที่อ่านได้ไม่อยู่ในตัวเลือก ให้กลับเป็นค่าเริ่มต้น
  6. PetGame.settings = s ให้ไฟล์อื่นอ่านค่าได้โดยตรง เช่น PetGame.settings.sfx

tone(freq, dur, o): เสียงโน้ตเดียว

  1. รวมตัวเลือกกับค่าเริ่มต้น: รูปคลื่น sine, ความดัง 0.5, หน่วงเวลา 0, ไม่เลื่อนเสียง
  2. t0 = currentTime + at เวลาเริ่มเล่น (หน่วงได้ เพื่อเรียงโน้ตเป็นทำนอง)
  3. createOscillator() ตัวกำเนิดคลื่นเสียง และ createGain() ตัวปรับความดัง
  4. ตั้งความถี่ (Hz) ถ้ามี to ใช้ exponentialRampToValueAtTime ไล่ความถี่ไปถึงค่าใหม่ เกิดเสียง "วู้ป" ขึ้นหรือลง
  5. ทำซองเสียง (envelope): เริ่มเงียบ 0.0001 → ดังเต็มใน 0.012 วินาที → ค่อยๆ เบาจนเงียบเมื่อจบ ป้องกันเสียงคลิก (ใช้ 0.0001 แทน 0 เพราะการไล่แบบ exponential ไปถึง 0 ไม่ได้)
  6. ต่อสาย oscillator → gain → ลำโพง (destination) แล้ว start/stop ตามเวลา

noise(dur, o): เสียงซ่า

  1. สร้างบัฟเฟอร์เสียงยาว dur วินาที แล้วเติมค่าสุ่มระหว่าง −1 ถึง 1 ทุกตัวอย่าง = เสียงรบกวนขาว (white noise)
  2. ผ่านตัวกรอง bandpass ให้เหลือเฉพาะช่วงความถี่รอบ freq เช่น 3500 Hz ได้เสียงฟองซ่าๆ, 900 Hz ได้เสียงเคี้ยว
  3. ความดังเริ่มที่ระดับเต็มแล้วจางลงจนเงียบ

notes(list, gap, o) เล่นโน้ตหลายตัวต่อกัน แต่ละตัวห่างกัน gap วินาที ใช้สร้างทำนองสั้น

ออบเจ็กต์ Sound

  • play(name) ไม่เล่นถ้าปิดเสียงเอฟเฟกต์ หรือไม่มีชื่อนี้ หรือ AudioContext ยังไม่ running (เบราว์เซอร์ห้ามเล่นเสียงก่อนผู้ใช้คลิกครั้งแรก) ครอบ try/catch ไว้
  • startMusic(scene) เริ่มเพลงครั้งเดียว (ถ้า this.music มีแล้วไม่สร้างซ้ำ) เล่นวน loop: true ถ้าเสียงยังถูกล็อก รอ event 'unlocked' ก่อน
  • stopMusic() หยุดและทำลายเพลง
  • setMusic(on, scene) / setSfx(on) บันทึกการตั้งค่าแล้วเปิด/ปิดตาม

หยุดเพลงเมื่อออกจากเกม

ดักเหตุการณ์ของหน้าเว็บ 4 อย่าง: visibilitychange (สลับแท็บ/ย่อหน้าต่าง), blur (ไปหน้าต่างอื่น), focus (กลับมา) และ pagehide (ปิดหน้า) ตอนออกเรียก pause() ตอนกลับเรียก resume() ซึ่งจะเล่นต่อก็ต่อเมื่อเพลงถูกพักอยู่ เปิดเพลงในการตั้งค่า และหน้าเว็บมองเห็นอยู่

serve.ps1 เซิร์ฟเวอร์สำหรับรันในเครื่อง · 45 บรรทัด

เปิดไฟล์ index.html ตรงๆ (file://) แล้วกล้องและบางฟีเจอร์จะใช้ไม่ได้ สคริปต์ PowerShell นี้จึงทำเว็บเซิร์ฟเวอร์เล็กๆ ที่ http://localhost:8080 โดยไม่ต้องติดตั้งอะไรเพิ่ม

  1. param([int]$Port = 8080, [switch]$Open) รับพอร์ต และสวิตช์ -Open เพื่อเปิดเบราว์เซอร์ให้อัตโนมัติ
  2. $root = โฟลเดอร์ที่สคริปต์อยู่ = โฟลเดอร์เกม
  3. สร้าง HttpListener ฟังที่ http://localhost:พอร์ต/ แล้ว Start()
  4. $mime ตารางนามสกุล → ชนิดไฟล์ บอกเบราว์เซอร์ว่าเป็น html/js/รูป/เสียง
  5. วนลูปรอคำขอ (GetContext() หยุดรอจนมีคนขอ):
    • แปลง path ใน URL เป็นชื่อไฟล์ (ถอดรหัส %20 เป็นเว้นวรรค) ถ้าว่างให้เป็น index.html
    • GetFullPath + StartsWith($root) ป้องกันการขอไฟล์นอกโฟลเดอร์เกม (เช่น ../../)
    • ถ้าเจอไฟล์: อ่านเป็นไบต์ ตั้งชนิดไฟล์ ใส่ Cache-Control: no-cache (แก้โค้ดแล้วรีเฟรชเห็นทันที) แล้วส่งกลับ
    • ถ้าไม่เจอ: ตอบ 404
    • finally ปิดการตอบทุกครั้ง แม้เกิดข้อผิดพลาด
  6. เมื่อหยุดสคริปต์ (Ctrl+C) finally นอกสุดสั่ง $listener.Stop()
