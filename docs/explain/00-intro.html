เริ่มต้นภาพรวมของเกมและวิธีอ่านเอกสารนี้

วิธีอ่าน

  • เอกสารเรียงตาม "ชั้น" ของโปรแกรม: ภาค 1 ส่วนที่ทำให้เกมเปิดได้ → ภาค 2–3 สมองของเกม (ข้อมูลสัตว์ AI แชทบอท) → ภาค 4–6 หน้าจอต่างๆ → ภาค 7 ควบคุมด้วยมือ → ภาค 8 หน้าตาและเครื่องมือ
  • แต่ละไฟล์มีหัวข้อสีเขียวมะกอก บอกชื่อไฟล์ หน้าที่ และจำนวนบรรทัด
  • ชื่อในกรอบ แบบนี้ คือชื่อจริงในโค้ด (ฟังก์ชัน ตัวแปร คลาส) ค้นหาในไฟล์ได้ทันที
  • ตัวเลขทุกตัว (เช่น เวลา ขนาด เกณฑ์) ตรงกับโค้ดเวอร์ชันปัจจุบัน

คำศัพท์ที่ใช้บ่อย

คำความหมาย
Phaserไลบรารีสร้างเกมบนเว็บ วาดภาพลง <canvas> จัดการฉาก รูปภาพ เสียง และการกดเมาส์
Scene (ฉาก)หน้าจอหนึ่งหน้าในเกม เช่น หน้าปก หน้าเลี้ยง ป๊อปอัปเมนู
Textureภาพที่ Phaser โหลดไว้ในหน่วยความจำ อ้างถึงด้วยชื่อ (key) เช่น body_cat_royal_4
Containerกล่องที่รวมวัตถุหลายชิ้น ย้าย ซ่อน หรือหมุนพร้อมกันได้
Graphicsวัตถุสำหรับวาดรูปทรง (สี่เหลี่ยม วงกลม เส้น) ด้วยโค้ด
Tweenแอนิเมชันที่เปลี่ยนค่าทีละน้อยตามเวลา เช่น เลื่อนตำแหน่ง ขยาย จาง yoyo = ไปแล้วกลับ repeat: -1 = วนไม่รู้จบ
Zoneพื้นที่สี่เหลี่ยมล่องหนที่รับการคลิก
depthลำดับชั้นการวาด ค่ามากอยู่บน
localStorageที่เก็บข้อมูลถาวรของเบราว์เซอร์ (ใช้เก็บเซฟและการตั้งค่า) แยกตามเว็บไซต์
event / listenerเหตุการณ์ (เช่น คลิก) และฟังก์ชันที่รอทำงานเมื่อเกิดเหตุการณ์นั้น
Promise / async / awaitวิธีเขียนงานที่ต้องรอ (เช่นขอใช้กล้อง โหลดไฟล์) โดยไม่ทำให้หน้าเว็บค้าง

เส้นทางของผู้เล่น

Boot→Title→START→Breed→Day 1→Game→หมดวัน: NEXT DAY→Day 2→Game→ผลวิวัฒนาการ→Evolution

หนึ่งเฟรมในหน้าเลี้ยงเกิดอะไรขึ้นบ้าง

  1. Phaser เรียก GameScene.update() ประมาณ 60 ครั้งต่อวินาที
  2. PetState.tick() ลดค่าสถานะตามเวลา และบันทึกพฤติกรรมของวัน
  3. ทุก 0.5 วินาที EmotionAI ตัดสินอารมณ์ → CareAdvisor เลือกคำแนะนำ → หน้าจอเปลี่ยนท่าทางและไฮไลต์ปุ่ม
  4. ทุก 0.2 วินาที วาดกล่องค่าสถานะและนาฬิกาใหม่ ทุก 5 วินาทีบันทึกเกม
  5. ผู้เล่นใช้ไอเทม → PetState.useItem() คำนวณผลและแต้มการดูแล
  6. หมดวัน กด NEXT DAY → EvolutionAI.analyze() ดูสัดส่วนการดูแลทั้งวัน ตัดสินว่าจะวิวัฒนาการ คงร่าง หรือถอยร่าง
  7. ผู้เล่นพิมพ์แชท → PetChatbot หาเจตนาและเลือกคำตอบตามอารมณ์และร่าง
