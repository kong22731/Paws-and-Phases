init(data): รับข้อมูลและรีเซ็ตค่า

รับ pet, fresh (เพิ่งเกิด), away (วินาทีที่ห่างไป) และ dayResult (ผลตัดสินตอนขึ้นวัน) แล้วรีเซ็ตตัวแปรสถานะทั้งหมด: อารมณ์ คำแนะนำ evolving (กำลังมีป๊อปอัปหรือวิวัฒนาการ = หยุดเกม) เวลาใช้ไอเทมล่าสุด ตัวจับเวลา 4 ตัว (ui, ai, save, fx) และสถานะเมนู Grooming

ทำไมต้องตั้งค่าอ้างอิงเป็น null: Phaser ใช้ออบเจ็กต์ฉากเดิมซ้ำทุกครั้งที่เริ่มฉากใหม่ (เช่นหลัง NEXT DAY) วัตถุบนจอของรอบก่อนถูกทำลายไปแล้ว ถ้าไม่ล้างตัวแปรที่ชี้ไปหามัน โค้ดอาจไปเรียกวัตถุที่ไม่มีอยู่แล้วจนเกิดข้อผิดพลาด

create(): สร้างหน้าเลี้ยง

  1. กำหนดพื้น (groundY = 552 ตำแหน่งเท้า) และตำแหน่งสัตว์กลางจอ (x = 480)
  2. วางพื้นหลังสวน และสี่เหลี่ยมน้ำเงินเข้มโปร่งใส 0 ไว้บนสุดชั้น 5 ชื่อ night (ตอนหลับจะทึบ 30% ให้ฉากมืด)
  3. สร้างส่วนต่างๆ: ตัวสัตว์ UI หลัก กล่องค่าสถานะ และเมนู Grooming
  4. สร้างข้อความแจ้งเตือน (toast) ล่างจอ เริ่มโปร่งใส และเริ่มเพลง
  5. แชท: เชื่อมแผงแชท ถ้าสัตว์เพิ่งเกิด หลัง 0.7 วินาทีให้พูดทักทาย และแจ้งในแชทว่าบันทึกอยู่ไฟล์ไหน (หรือเตือนว่าไฟล์เต็ม) ถ้าห่างไปเกิน 1 นาทีแจ้งระยะเวลา แล้วแจ้ง "Day N"
  6. คำนวณ AI ครั้งแรก (บังคับ) วาด UI และถ้ามีผลตัดสินวัน แสดงหลัง 0.25 วินาที
  7. บันทึกก่อนออก: ฟังก์ชัน onHide ถ้าสัตว์มีไฟล์ → autosave ถ้ายังไม่มีไฟล์และกำลังปิดหน้า (beforeunload) → preventDefault() ทำให้เบราว์เซอร์ถามยืนยันก่อนปิด ผูกไว้กับการปิดหน้าและการสลับแท็บ
  8. ผูก event resume (กลับจากป๊อปอัป) และเมื่อฉากปิด (shutdown) ถอดทุกอย่างที่ผูกไว้ กันฟังก์ชันของฉากเก่าทำงานซ้อน

ตัวสัตว์

buildPet(): ชั้นของตัวสัตว์

สัตว์ซ้อนอยู่ใน Container 3 ชั้น เพื่อให้แอนิเมชันหลายอย่างทำงานพร้อมกันได้โดยไม่ทับกัน:

ชั้นใช้กับ
petC (นอกสุด)ตำแหน่งเดินไปมา และท่าตอนใช้ไอเทม (กระโดด ยุบ)
petStepจังหวะก้าวเดิน (เด้ง เอียง) และสั่นตอนทำไม่ได้
petBodyท่าประจำร่างและอารมณ์ (หายใจ ลอย ส่าย ตัวสั่น)
petImg (ในสุด)ภาพจริง ยึดจุดที่เท้า (setOrigin(0.5, 1)) กดแล้วลูบหัว

นอกจากนี้สร้าง: เงาวงรี, ฟองอารมณ์ (วงกลมขาวขอบฟ้า + วงเล็ก 2 วงเป็นหาง + อีโมจิ) และ ฟองคำพูด (กราฟิกพื้น + ข้อความตัดบรรทัดที่ 340 พิกเซล useAdvancedWrap ตัดคำภาษาไทยได้)

petTexture() และ refreshPetLook()

  • petTexture: ถ้าเป็นหมาร่างแรกที่กำลังหลับ ใช้ภาพนอนจากดีไซน์ ไม่งั้นใช้ภาพร่างปัจจุบัน
  • refreshPetLook: เปลี่ยนภาพ จำสถานะหลับที่แสดงอยู่ ย่อขยายตามความสูงประจำร่าง (ร่าง 1–5 = 270, 280, 290, 300, 310 พิกเซล ภาพนอน 170) ไม่ให้กว้างเกิน 340 คำนวณขอบบนของตัว (petTop) ปรับความกว้างเงา (70% ของตัว ไม่เกิน 260) ย้ายฟองอารมณ์ไปมุมขวาบนของตัว ย้ายฟองคำพูดไว้เหนือหัว (ไม่สูงกว่า y 215) และอัปเดตรูปหัวมุมซ้ายบน

  3. ฉากมืดถ้าหลับ ถ้าสถานะหลับเปลี่ยนจากที่แสดงอยู่ เปลี่ยนภาพ

  5. อัปเดตนาฬิกาและการ์ดพักผ่อน

เมนู Grooming

buildGrooming()

  1. Container groomC ชั้น 70 เริ่มซ่อน: แผงขาวด้านบน + zone รับคลิกกันทะลุ + ปุ่มย้อนกลับ + ปุ่มปิด
  2. หน้าเลือกหมวด (groomMenu): ป้าย "Grooming" และการ์ด 4 หมวด สีตาม CATEGORIES กดแล้วไปหน้าของหมวดนั้น
  3. หน้าไอเทม (itemsC): Container itemRows ใส่การ์ด ใช้ mask (หน้ากาก) สี่เหลี่ยม 862×170 = แสดงเฉพาะส่วนที่อยู่ในกรอบ การ์ดแถวที่เลื่อนออกไปจึงถูกซ่อน มีรางและปุ่มแถบเลื่อนด้านขวา
  4. หน้าพักผ่อน (restC): การ์ดใหญ่ 2 ใบ Nap และ Sleep เก็บ title/sub ไว้เปลี่ยนข้อความเป็น "Wake up" ตอนหลับ
  5. groomGlowIn กรอบเหลืองกระพริบสำหรับไฮไลต์การ์ดข้างใน
  6. การเลื่อนรายการ 3 วิธี: ล้อเมาส์ (เมื่อชี้อยู่บนแผง y < 190), ลากขึ้นลงเกิน 30 พิกเซล (จำจุดเริ่มตอนกด เทียบตอนปล่อย), กดบนรางแถบเลื่อน (เหนือหรือใต้กึ่งกลางปุ่ม)
เมธอดการทำงาน
openGrooming()ไม่เปิดถ้ามีป๊อปอัปหรือเปิดอยู่แล้ว ถ้าหมดวันแจ้งเตือนพร้อมเสียง error ไม่งั้น: เสียง open, แผงเลื่อนลงพร้อมค่อยๆ ปรากฏ, UI หลักจางหาย, กล่องค่าสถานะเลื่อนลงใต้แผง แล้วแสดงหน้าเลือกหมวด
closeGrooming()ย้อนกลับทุกอย่าง: แผงเลื่อนขึ้นหาย UI หลักกลับมา กล่องค่ากลับที่เดิม
showGroomView(view)แสดงหน้าที่ตรงกับ view ซ่อนหน้าอื่น ปุ่มย้อนกลับแสดงเมื่อไม่ใช่หน้าเลือกหมวด ถ้าเป็นหน้าไอเทมสร้างการ์ดใหม่ แล้วอัปเดตการ์ดพักผ่อนและไฮไลต์
buildItemCards(catKey)ลบการ์ดเก่า สร้างใหม่แถวละ 4 ใบ (x ตามตาราง 4 ตำแหน่ง, y เพิ่มทีละ 150 ทุก 4 ใบ: Math.floor(i/4)) คำนวณจำนวนแถว รีเซ็ตการเลื่อน
scrollItems(dir)แถวใหม่ = แถวเดิม ± 1 บีบให้อยู่ระหว่าง 0 ถึงแถวสุดท้าย ถ้าไม่เปลี่ยนไม่ทำอะไร ไม่งั้นเลื่อน itemRows ไป −150 × แถว (ระหว่างเลื่อนวาดไฮไลต์ตามทุกเฟรมผ่าน onUpdate)
drawScrollbar()มีแถวเดียวซ่อนแถบ ไม่งั้นปุ่มเลื่อนสูง 161/จำนวนแถว อยู่ตามแถวปัจจุบัน และจำกึ่งกลางไว้ใน thumbMid
refreshRestCards()การ์ดที่ตรงกับการหลับตอนนี้เปลี่ยนเป็น "Wake up" และบอกวินาทีที่เหลือ (งีบ) หรือ "(Sleeping...)" (นอน)

ลูปหลักและการเดิน

update(time, delta): ทำงานทุกเฟรม

  1. ถ้ามีป๊อปอัปหรือวิวัฒนาการ หยุด
  2. แปลง delta (มิลลิวินาที) เป็นวินาที ตัดไม่เกิน 0.25 วินาที (ถ้าเครื่องค้างไปนาน จะไม่กระโดดเวลาทีเดียวมากๆ)
  3. pet.tick(dt × ความเร็ว) เดินเวลาของสัตว์
  4. ตัวจับเวลาแยกความถี่ ไม่ต้องทำทุกอย่างทุกเฟรม: UI ทุก 0.2 วิ, AI ทุก 0.5 วิ, autosave ทุก 5 วิ, เอฟเฟกต์รอบตัวทุก 1.4 วิ
  5. อัปเดตการเดิน
  6. ถ้าเพิ่งหมดวัน (ทำครั้งเดียวด้วย dayEndNotified): ปิด Grooming เล่นเสียง แจ้งให้กด NEXT DAY

updateWalk(delta) และ walkTo(target)

  • ทุกเฟรม: ให้เงา ฟองอารมณ์ และฟองคำพูด (บีบไม่ให้ออกนอกจอ) ตามตำแหน่งตัวสัตว์
  • ถ้ากำลังเดินอยู่ไม่ทำอะไรต่อ ไม่งั้นนับถอยหลัง ครบแล้วสุ่มรอบถัดไป 3.5–7.5 วินาที
  • ไม่เดินถ้าหลับ หมดวัน หรืออารมณ์ป่วย/เหนื่อย สุ่มจุดหมาย x 330–690 ถ้าใกล้จุดเดิมไม่ถึง 80 พิกเซล ขยับออกไปอีก 140
  • walkTo: กลับด้านภาพเมื่อเดินไปทางขวา (ภาพส่วนใหญ่หันซ้าย) ถ้าเป็นแบบลอยใช้เอียงซ้ายขวา ไม่งั้นเด้งขึ้นลง + เอียง ทั้งหมดวนไม่รู้จบ แล้วเลื่อน petC ไปจุดหมายใช้เวลา = ระยะทาง/ความเร็ว เมื่อถึงหยุดท่าก้าว คืนท่าตรง และตั้ง active = false

AI และอารมณ์

updateAI(force) (ทุก 0.5 วินาที)

  1. ประเมินอารมณ์ เช็กว่าเปลี่ยนจากเดิมไหม ขอคำแนะนำจาก CareAdvisor และวาดไฮไลต์
  2. ถ้าอารมณ์เปลี่ยน (หรือบังคับ): เปลี่ยนท่าทาง อีโมจิในฟองและที่รูปหัว อีโมจิในแชท ถ้าเปลี่ยนเป็นอารมณ์ที่ต้องการอะไรบางอย่างและเข้มพอ (> 0.2) ให้สัตว์เรียกผู้เล่นทันที
  3. ถ้ายังต้องการอยู่และเข้ม > 0.35 เรียกซ้ำได้ทุก 20 วินาที

applyEmotionAnimation(emo)

  1. หยุดแอนิเมชันเก่าของ petBody คืนตำแหน่ง ขนาด มุม และสีเดิม
  2. loop(cfg) ทางลัดสร้างแอนิเมชันวนไปกลับไม่รู้จบ
  3. อารมณ์ปกติ หรือดีใจขณะมีสายแล้ว → ใช้ท่าประจำสาย ('style:' + idle) อารมณ์อื่นใช้ท่าตามอารมณ์
  4. switch แต่ละท่า เช่น
    • hop: กระโดด 30 พิกเซล พัก 0.7 วินาที
    • breathe: ยืดตัว 3% ช้าๆ
    • float: ลอยขึ้นลง 14 + เอียง ±2°
    • flex: กระโดดเบ่งกล้าม + ขยายข้าง
    • nod: เอียง 3° ค้าง (hold) แล้วกลับ = พยักหน้า
    • look: เลื่อนไปข้าง 26 ค้างไว้ = มองหา (เหงา)
    • droop: ตัวยุบ + ย้อมสีฟ้าซีด (เศร้า)
    • yawn: ย้อมเทา ยุบตัว (เหนื่อย)
    • shiver: สั่นซ้ายขวาเร็วมาก 60 มิลลิวินาที + ย้อมเขียว (ป่วย)
    • sleep: เอียง −4° (ยกเว้นภาพนอน) ย้อมน้ำเงิน หายใจช้า
  5. ฟองอารมณ์แสดงเฉพาะเมื่อมีความต้องการหรือกำลังหลับ และขยายหดเรียกความสนใจ

ambientFx() และ floatEmoji()

ทุก 1.4 วินาที ลอยอีโมจิตามอารมณ์ (ดีใจ 💖, หลับ 💤, เศร้า 💧, ป่วย 🦠 โอกาสครึ่งหนึ่ง) ถ้าอารมณ์ปกติ มีโอกาส 35% ลอยเอฟเฟกต์ประจำสาย floatEmoji สร้างข้อความอีโมจิ ลอยขึ้น 70 พิกเซลพร้อมจางหายใน 1.6 วินาทีแล้วทำลายตัวเอง

การใช้ไอเทม

useItem(key, card)

  1. ไม่ทำงานระหว่างป๊อปอัป และต้องเว้น 1 วินาทีจากครั้งก่อน (กันกดรัว)
  2. ให้ PetState คำนวณผล แสดงข้อความ เล่นเสียงตามหมวด (ทำไม่ได้ = error, พัก = sleep/wake, กิน = eat, เล่น = play, ดูแล = care)
  3. ทำไม่ได้: สัตว์ส่ายหัวซ้ายขวา 4 ครั้งแล้วจบ
  4. ทำได้: เล่นเอฟเฟกต์ไอเทม แสดงตัวเลขที่เปลี่ยน (+เขียว / −แดง พร้อมอีโมจิค่าสถานะ) เรียงลงมาข้างตัว ลอยขึ้นแล้วหาย
  5. อัปเดต AI และ UI แล้วบันทึกทันที

playItemFx(item, card)

หาตำแหน่งการ์ดบนจอจริงด้วย getWorldTransformMatrix() (การ์ดอยู่ใน Container ซ้อนกัน ตำแหน่งของมันเองเป็นตำแหน่งสัมพัทธ์) ใช้เป็นจุดเริ่มของภาพไอเทมที่บินออกมา (flyer)

  • กิน: อาหารบินไปที่ปาก ย่อเหลือ 60% แล้วหายไป สัตว์ยุบตัว 3 ครั้ง = เคี้ยว (วิตามินมีประกาย ✨)
  • เล่น: ของเล่นพุ่งจากซ้ายไปขวา โค้งขึ้นสูงเหนือหัว หมุน 540° สัตว์กระโดด 2 ครั้ง
  • ดูแล: อุปกรณ์ไปที่ตัวแล้วถูไปมา ฟองสบู่และประกาย 14 ชิ้นลอยขึ้นทีละชิ้น สัตว์ส่ายตัว
  • พัก: อีโมจิ 💤 (หลับ) หรือ ☀️ (ตื่น)

การควบคุมด้วยมือในหน้าเลี้ยง

toggleHand()

เปิดอยู่ → ปิดและแจ้ง "Mouse control" ปิดอยู่ → แจ้ง "Starting camera…" เรียก Hand.start() รอผลแล้วแจ้งว่าเปิดสำเร็จ (กำมือเพื่อกด) หรือกล้องใช้ไม่ได้

setupHand()

  • refresh(on) แสดงพื้นฟ้าที่ปุ่มกล้องเมื่อเปิดมือ
  • petImg.noDwell = true บอกระบบมือว่าชี้ค้างบนตัวสัตว์ไม่ใช่การกดปุ่ม (เป็นการลูบหัวแทน)
  • ready() ใช้ท่ามือได้เฉพาะเมื่อฉากทำงาน ไม่มีป๊อปอัป และไม่ได้เปิด Grooming
  • 🤚 ลูบหัว (onFrame) เรียกทุกเฟรมของกล้อง: แปลงตำแหน่งถุงมือเป็นพิกัดเกม เช็กว่าแบมือ ไม่ได้กำ และอยู่บนตัวสัตว์ (getBounds().contains) ถ้าไม่ใช่รีเซ็ต ถ้าใช่ครั้งแรกจำเวลา ลูบครั้งแรกหลัง 0.8 วินาที แล้วทุก 1.4 วินาทีตราบที่มือยังวางอยู่
  • ✌️ ทักทาย (onPeace) ถ้าหลับพูด "Zzz" ไม่งั้นเสียง chat กระโดด 2 ครั้ง ลอย ✌️ และพูดทักทายแบบสุ่ม
  • 👍 ชม (onThumb) ได้ Social +2 เฉพาะเมื่อห่างจากครั้งก่อนเกิน 8 วินาที (ถ้าได้ลอย 💗 ด้วย) ตัวยืดหดดีใจ ลอย 👍 และพูดขอบคุณ
  • สมัครรับ event 4 ตัวจากระบบมือ และยกเลิกทั้งหมดเมื่อฉากปิด

วันใหม่ ป๊อปอัป และวิวัฒนาการ

เมธอดการทำงาน
nextDay()ใช้ได้เมื่อหมดวันเท่านั้น ให้ PetState ตัดสินวัน บันทึก แล้วไปฉาก Day พร้อมผล
showDayResult(r)evolve/regress → หยุดฉาก เปิดฉาก Evolution ทับ, warn → เตือนในแชทว่าเหลือกี่วันก่อนถอยร่าง และให้สัตว์พูด, near → บอกว่าเกือบถึงเป้า, stay ร่าง 1 → แนะนำให้เลี้ยงแบบเดียวทั้งวัน, max → บอกให้กด Rebirth
confirmRebirth()ยังไม่ถึงร่าง 5 แจ้งเตือน ถึงแล้วถามยืนยัน กด YES → rebirth บันทึก และไปฉาก Day
openPopup(key)ปิดถาดแชท ตั้ง evolving = true (หยุด update) จำว่าเปิดอะไร scene.pause() หยุดฉากนี้ แล้ว scene.launch(key) เปิดฉากป๊อปอัปทับ (ส่งสัตว์และตัวฉากไปด้วย)
onResume()เรียกเมื่อป๊อปอัปปิด: เลิกหยุด เช็กว่าความเร็วเปลี่ยนไหม ถ้ากลับจากวิวัฒนาการ: เปลี่ยนภาพ คำนวณ AI อัปเดตหัวแชท แจ้งในแชท และให้สัตว์พูดถึงร่างใหม่ (หรือร่างที่ถอยกลับ)
speedChanged()ถ้าความเร็วต่างจากที่จำไว้ แจ้ง "Time speed xN" (ครั้งแรกแค่จำ ไม่แจ้ง)
