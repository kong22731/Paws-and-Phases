migrate(): แปลงเซฟรุ่นเก่า

  1. ถ้าชื่อสายอยู่ใน LEGACY_LINES เปลี่ยนเป็นชื่อใหม่ ถ้าเป็นชื่อที่ไม่รู้จักเลย ใช้ 'playful'
  2. unlocked: ใช้ regex /^(dog|cat)_([a-z]+)_(\d)$/ แยกชื่อร่าง เช่น dog_beauty_3 ออกเป็น ชนิด/สาย/ขั้น แล้วประกอบใหม่ด้วยชื่อสายใหม่ (dog_selfcare_3)
  3. history: แปลงชื่อสายในแต่ละรายการแบบเดียวกัน
  4. เติมฟิลด์ที่เซฟเก่าไม่มี: careWindow.chat, sleepMode (ถ้าหลับอยู่ = 'auto'), completed, dayTime
  5. ถ้าเซฟเก่าอยู่ร่าง 5 แล้ว ให้นับว่าสำเร็จสายนั้น

tick(dt): เดินเวลา (เรียกทุกเฟรมจาก GameScene)

dt = จำนวนวินาทีในเกมที่ผ่านไปตั้งแต่เฟรมก่อน (คูณความเร็วแล้ว)

  1. ถ้าหมดวันแล้ว ตรึง dayTime ไว้ที่ค่าสูงสุดแล้วออกทันที ค่าสถานะไม่ลดอีก
  2. ตัด dt ไม่ให้เกินเวลาที่เหลือของวัน แล้วบวกเข้า gameTime และ dayTime
  3. ถ้ากำลังหลับ: พลัง +0.8×dt, ความอิ่ม −0.10×dt ถ้าเป็นการงีบหรือนอนที่ผู้เล่นสั่ง ได้แต้ม rest เพิ่ม 0.06×dt จากนั้นเช็กการตื่น: งีบ → ตื่นเมื่อถึง napUntil, หมดแรงหลับเอง → ตื่นเมื่อพลังเต็ม 100, นอนกลางคืน → ไม่ตื่นเอง
  4. ถ้าตื่นอยู่: ค่าทั้ง 4 ลดตามอัตรา DECAY ถ้าไม่ได้ยุ่งเกิน 60 วินาที ความสุขลดเพิ่ม ถ้าพลังเหลือ ≤ 3 จะหลับเอง (sleepMode 'auto')
  5. ไม่ว่าหลับหรือตื่น: ถ้าความอิ่มต่ำกว่า 20 สุขภาพลดเพิ่ม
  6. บันทึกพฤติกรรม: เวลาเพิ่ม, wellSum += ความเป็นอยู่×dt (ใช้หาค่าเฉลี่ยทั้งวันภายหลัง) และถ้าค่าใดใน อิ่ม/สุข/สุขภาพ ต่ำกว่า 25 นับเวลาเป็น "ถูกละเลย"
สำคัญ: เวลาเดินเฉพาะตอนอยู่หน้าเลี้ยงเท่านั้น ปิดเกมหรือสลับแท็บแล้วค่าจะคงเดิม ไม่มีการชดเชยเวลาที่ปิดไป

nextDay(): ขึ้นวันใหม่ (กดปุ่ม NEXT DAY)

  1. เรียก EvolutionAI.analyze(careWindow, stage) วิเคราะห์การเลี้ยงทั้งวัน
  2. เก็บข้อมูลร่างก่อนเปลี่ยน (from) ไว้ให้ฉากวิวัฒนาการแสดง
  3. ตัดสินผล (type):
    • max: อยู่ร่าง 5 แล้ว ไม่เปลี่ยนอะไร (ต้องกด Rebirth)
    • ร่าง 1: ถ้าผ่านสายใดสายหนึ่ง → evolve เข้าร่าง 2 ของสายนั้น ไม่ผ่าน → stay
    • ร่าง 2–4 และผ่านเป้าสายเดิม → evolve ขึ้น 1 ขั้น รีเซ็ต missStreak
    • ไม่ผ่าน แต่ผ่านถ้าใช้ "เกณฑ์แบบง่าย" (เรียก analyze ด้วย stage 1) → near คงร่าง ไม่นับว่าพลาด
    • ไม่ผ่านเลย → missStreak +1 ถ้าครบจำนวนที่อนุญาต → regress ลด 1 ขั้น ไม่งั้น → warn เตือนเฉยๆ
  4. ถ้าเพิ่งถึงร่าง 5 บันทึกสายนั้นใน completed
  5. เริ่มวันใหม่: ถ้าทั้งวันไม่คุยเลย Social −8, วัน +1, dayTime = 0, ล้าง careWindow ถ้านอนกลางคืนอยู่ พลังเต็ม 100 แล้วปลุก, ตั้ง lastInteraction ใหม่ (ไม่ให้เหงาทันทีตอนเช้า)
  6. คืน { type, from, result } ให้ฉาก Day/Evolution ใช้แสดงผล

เมธอดเกี่ยวกับการลดร่างและเกิดใหม่

  • missesAllowed() พลาดได้กี่วันจาก REGRESS_AFTER (ไม่มีค่าใช้ 2) และ missesLeft() เหลืออีกกี่วัน
  • regress() ลดขั้น 1 (ไม่ต่ำกว่า 1) ถ้ากลับเป็นร่าง 1 ล้างสาย และบันทึกลงประวัติพร้อม regress: true
  • rebirth() กลับเป็นร่าง 1 วัน 1 ค่าสถานะ 80 ทุกตัว แต่ เก็บ ชื่อ ร่างที่ปลดล็อก และสายที่สำเร็จไว้

useItem(key): ใช้ไอเทม

คืน { ok, message, deltas, item }

  1. หาไอเทม ไม่เจอ → ok: false
  2. เก็บค่าสถานะก่อนใช้ (before) และหาค่าสถานะที่หมวดนี้เกี่ยวข้อง (statKey)
  3. ปฏิเสธถ้าหมดวันแล้ว หรือกำลังหลับแต่ไม่ได้กดไอเทมหมวดพักผ่อน
  4. คำนวณคุณค่าการดูแล: need = (100 − ค่าที่เกี่ยวข้อง)/100 แล้ว careValue = 10 × (0.5 + need) ยิ่งสัตว์ต้องการมาก ยิ่งได้แต้มมาก (5–15 แต้ม) แต้มนี้ใช้ตัดสินสายวิวัฒนาการ
  5. หมวดพักผ่อน: ถ้าหลับอยู่ = ปลุก (ไม่ได้แต้ม ถ้าพลังยังไม่ถึง 50 ความสุข −5 "ตื่นเร็วไป") ถ้าตื่นอยู่ = เริ่มงีบ 30 วินาที หรือนอนยาว ถ้าพลังเกิน 85 อยู่แล้วได้แค่ 1 แต้ม
  6. หมวดอื่น: ถ้าจะเล่นแต่พลังต่ำกว่า 15 → ปฏิเสธ ไม่งั้นบวกผล fx ทุกตัวเข้าค่าสถานะ แล้วเช็กกรณีพิเศษ:
    • ให้อาหารตอนอิ่มเกิน 90 → สุข −5 สุขภาพ −5 ได้ 1 แต้ม "Too full!"
    • ให้วิตามินตอนสุขภาพเกิน 50 → สุข −5 ได้ 2 แต้ม
    • อาบน้ำตอนสะอาดเกิน 90 → ได้ 1 แต้ม
    • ปกติ → ข้อความตามหมวด เช่น "Yum! Delicious!"
  7. บวกแต้มเข้า careWindow ของหมวดนั้น นับจำนวนครั้งรวม และอัปเดตเวลาที่ยุ่งล่าสุด
  8. คำนวณ deltas = ค่าหลัง − ค่าก่อน ของแต่ละสถานะ (ปัดเศษ) ใช้แสดงตัวเลข +/− ลอยบนจอ

evaluate(pet)

  1. ถ้าหลับ → ตอบ sleeping ทันที
  2. คำนวณคะแนน (ยิ่งค่าต่ำกว่าเกณฑ์มาก คะแนนยิ่งสูง):
    อารมณ์สูตร
    sickสุขภาพ < 35 → (35 − สุขภาพ) × 3
    hungryอิ่ม < 40 → (40 − อิ่ม) × 2.5
    tiredพลัง < 30 → (30 − พลัง) × 2.5
    lonelyไม่ได้ยุ่ง > 45 วิ และสุข < 65 → min(60, (เวลา−45)/2) + (65 − สุข)
    sadสุข < 35 → (35 − สุข) × 2
    happyเฉลี่ย > 70 และสุข > 65 → เฉลี่ย − 55
    normalคงที่ 12 (เป็นค่าตั้งต้นที่ต้องชนะ)
  3. วนหาคะแนนสูงสุด และคำนวณความเข้ม intensity = คะแนน/80 (ไม่เกิน 1)

  • ถ้าพลังต่ำกว่า 15 ลดคะแนน play เหลือ 20% (เหนื่อยเกินจะเล่น)
