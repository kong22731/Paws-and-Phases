แชทบอทนี้ ไม่ใช้ AI ออนไลน์หรือ API ทำงานออฟไลน์ด้วย "กฎ" 2 ขั้น: (1) จับ เจตนา (intent) จากคำสำคัญในข้อความ (2) เลือกคำตอบตามเจตนา อารมณ์ ชนิดสัตว์ ระดับความผูกพัน และร่างปัจจุบัน แล้วปรับสำนวนให้เข้ากับบุคลิกของร่าง

INTENTS: รายการเจตนา 37 แบบ

แต่ละรายการมี key และ words = คำที่ถ้าพบในข้อความถือว่าเป็นเจตนานี้ ลำดับมีผล เพราะตรวจจากบนลงล่าง เจอแบบแรกก็หยุด เจตนาที่เจาะจงจึงต้องอยู่ก่อนเจตนากว้างๆ เช่น "ฉันเหนื่อย" (userSad) ต้องตรวจก่อน "เหนื่อย" (sleep) ไม่งั้นสัตว์จะคิดว่าผู้เล่นถามเรื่องง่วงนอน แบ่งเป็นกลุ่ม:

  • ความรู้สึกผู้เล่น: userSad, userHappy, sorry
  • คุยเล่น: favFood, hobby, color, age, time, weather, dream, joke, sing, dance, friend, family, home, study, animal, bored, math (คำว่างเพราะตรวจด้วย regex แยก)
  • การดูแล: advice, status, hunger, play, sleep, bath, evolve, name, love, praise, scold, greet, bye, thanks
  • ตอบสั้น: yes, no (อยู่ท้ายสุด เพราะคำว่า "ไม่" ปรากฏในประโยคอื่นบ่อย)

BY_LINE: คำตอบตามสาย

คำถาม 4 หัวข้อ (อาหารโปรด งานอดิเรก สีที่ชอบ ความฝัน) มีคำตอบแยกตามสาย สัตว์แต่ละร่างจึงมีนิสัยต่างกัน เช่นถามอาหารโปรด สาย gluttony ตอบ "ทุกอย่าง!" สาย selfcare ตอบ "ผลไม้ล้างสะอาดแล้วเท่านั้น"

  • lineKey(pet) ถ้ามีสายและร่างเกิน 1 ใช้ชื่อสาย ไม่งั้นใช้ 'baby'
  • byLine(topic, pet) สุ่มคำตอบของหัวข้อนั้นตามสาย ถ้าสายนั้นไม่มีคำตอบ ใช้ของ baby

แต่ละสายแบ่ง 2 ช่วง: low = ร่าง 2–3 และ high = ร่าง 4–5 (ร่าง 1 พูดปกติ) ตัวเลือกที่ใช้ได้:

ALIEN คำต่างดาว 12 คำ และ ALIEN_ACT ท่าทาง 5 แบบ ใช้กับสาย neglect ร่าง 4–5

personaOf(pet) และ voice(text, pet)

personaOf คืนบุคลิกที่ตรงกับสายและช่วงร่าง (ร่าง 1 หรือไม่มีสาย คืน null) ส่วน voice แปลงประโยคตามบุคลิก:

  1. ไม่มีบุคลิกหรือไม่มีข้อความ → คืนเดิม
  2. gibberish: นับจำนวนคำจากความยาวประโยคเดิม (ยาว 9 ตัวอักษรต่อ 1 คำ ระหว่าง 2–6 คำ) สุ่มคำต่างดาวมาต่อกัน ลงท้าย "!" หรือ "..." แล้วเติมท่าทาง
  3. แทนที่ "เรา" และ "เธอ" ด้วย regex /เรา/g (g = ทุกตำแหน่ง)
  4. slow: แทนที่ช่องว่างด้วย "... " (ยกเว้นช่องว่างก่อน ๆ ใช้ (?!ๆ) = "ไม่ได้ตามด้วย ๆ") และเปลี่ยน ! เป็น ...
  5. ถ้าข้อความเป็นท่าทางล้วน (ขึ้นต้นด้วย "(" ลงท้ายด้วย ")") คืนไปเลย
  6. ประกอบ: คำนำหน้าสุ่ม + ข้อความ + คำลงท้ายสุ่ม

detectIntent(text)

  1. แปลงเป็นตัวพิมพ์เล็กและลบช่องว่างทั้งหมด (/\s+/g) "สวัส ดี" กับ "สวัสดี" จึงจับได้เหมือนกัน
  2. ถ้าตรงรูปแบบ "ตัวเลข เครื่องหมาย ตัวเลข" (เช่น 12×3) → 'math'
  3. วน INTENTS ตามลำดับ ถ้าข้อความมีคำใดคำหนึ่ง (includes) → คืน key นั้น
  4. ไม่เจอเลย → 'unknown'

calc(text)

ใช้ regex /(\d+)\s*([+\-x×*÷/])\s*(\d+)/ ดึงตัวเลข 2 ตัวและเครื่องหมาย คำนวณจากตารางเครื่องหมาย (หารด้วย 0 ได้ NaN) ปัดทศนิยม 2 ตำแหน่ง ถ้าผลไม่ใช่ตัวเลขจริงคืน r: null

reply(text, ctx): ฟังก์ชันหลักที่ ChatPanel เรียก

  1. หาเจตนา
  2. เรียก replyFor ได้คำตอบพื้นฐาน แล้วผ่าน voice ปรับบุคลิก
  3. ถ้าเป็นเอเลี่ยน คืนทันที
  4. เลือกเสียงร้อง: มีบุคลิก → สุ่มจาก sound (รวมตัวเลือกว่าง) ไม่มี → หมา "โฮ่ง!/บ๊อก ๆ" แมว "เมี้ยว~/เหมียว" ถ้าไม่ได้หลับ โอกาส 60% ต่อท้ายเสียงร้อง
  5. คืน { intent, text }

replyFor(intent, ctx, text): เลือกคำตอบ

ดึงอารมณ์ ค่าสถานะ ระดับความผูกพัน และชนิดสัตว์มาใช้

  • ถ้าหลับ ตอบแบบละเมอ เช่น "Zzz... งื้อ..." (ยกเว้นบอกลา)
  • urgent ประโยคความต้องการเร่งด่วนตามอารมณ์ (hungry, sick, tired, lonely, sad) จะแทรกในบางคำตอบ

การส่งและแสดงข้อความ

send(text):

  1. ตัดช่องว่างหัวท้าย ถ้าว่างหรือไม่อยู่หน้าเลี้ยงไม่ทำอะไร
  2. ล้างช่องพิมพ์ ปิดถาด แสดงข้อความผู้เล่น เล่นเสียง send
  3. ขอข้อมูลจากฉาก (getAIContext() = สัตว์ อารมณ์ คำแนะนำ) แล้วให้ PetChatbot คิดคำตอบ
  4. แจ้งฉาก (onChat(res)) ให้นับการคุยและให้สัตว์มีท่าทาง
  5. แสดง "• • •" (กำลังพิมพ์) 600 มิลลิวินาที แล้วแทนด้วยคำตอบจริงพร้อมเสียง chat และบรรทัด meta
  • petSays(text) สัตว์พูดเอง (ไม่ได้ตอบผู้เล่น) เช่นเรียกเมื่อหิว
  • system(text) ข้อความระบบตัวเล็กกลางแผง
  • add(who, text, meta) สร้างแถวข้อความ: system เป็นข้อความเปล่า, pet มีรูปหัวนำหน้า, ข้อความอยู่ในฟองคำพูด ใช้ textContent (ไม่ใช่ innerHTML) จึงปลอดภัยจากการแทรกโค้ด HTML แล้วเลื่อนลงล่างสุด

พูดด้วยเสียง (listen / stopListening)

  1. ใช้ Web Speech API (SpeechRecognition หรือ webkitSpeechRecognition) ถ้าเบราว์เซอร์ไม่มี แจ้งให้ใช้ Chrome/Edge
  2. ถ้ากำลังฟังอยู่แล้ว กดซ้ำ = หยุด
  3. ตั้งภาษา th-TH และ interimResults = แสดงข้อความระหว่างพูดได้
  4. onresult รวมข้อความที่ได้ใส่ช่องพิมพ์ ถ้าผลสุดท้าย (isFinal) ส่งทันที
  5. onerror แจ้งข้อผิดพลาด (ยกเว้น aborted ซึ่งเกิดเมื่อเราสั่งหยุดเอง), onend หยุด
  6. ใส่คลาส listening ให้ปุ่มไมค์เปลี่ยนสี แล้ว start()

clickable(scene, c, w, h, onClick)ทำให้วัตถุกดได้: Container ต้องกำหนดขนาดก่อน, useHandCursor เปลี่ยนเคอร์เซอร์เป็นรูปมือ, เมาส์ชี้ขยาย 1.04 เท่า, ออกกลับ 1, กดยุบ 0.95 แล้วเด้งกลับ (yoyo) เล่นเสียง click (เว้นแต่ c.silent) แล้วเรียก onClick
bar(...)ปุ่มแถบยาว: Container ที่มีกล่องพื้น + ข้อความ (ชิดซ้ายห่าง 24 หรือกึ่งกลาง) + ลูกศรวงกลมด้านขวาถ้า arrow เก็บข้อความไว้ที่ c.label เพื่อเปลี่ยนภายหลังได้
iconButton(...)ปุ่มสี่เหลี่ยมมีไอคอน (แถบขวาหน้าเลี้ยง) ถ้า icon เป็นสตริงใช้ภาพ ui_ชื่อ ถ้าเป็นฟังก์ชันให้ฟังก์ชันนั้นวาดไอคอนเอง
imageButton(...)ภาพเปล่าที่กดได้ (ปุ่มปิด/ย้อนกลับ) ชี้แล้วจางลงเล็กน้อย
pillMeter(...)แถบค่าแบบเม็ดยา: กรอบขาวขอบสี + แถบเติม คืนออบเจ็กต์ที่มี set(v) ซึ่งบีบค่า 0–100 ข้ามการวาดถ้าค่าเปลี่ยนน้อยกว่า 0.05 (ประหยัดเพราะเรียกทุกเฟรม) และความกว้างขั้นต่ำเท่าความสูง ให้ปลายยังกลม
meter(...)แถบค่าแบบเรียบ ใช้ในฉากวิวัฒนาการ หลักการเดียวกัน
dim(scene, alpha)สี่เหลี่ยมดำโปร่งเต็มจอ setInteractive() ทำให้มัน "รับ" การคลิกไว้ จึงกดทะลุไปโดนของข้างหลังไม่ได้
confirm(scene, message, onYes, o)กล่องยืนยันในเกม (ใช้แทน window.confirm ที่บางเบราว์เซอร์บล็อก) สร้าง Container ชั้นบนสุด (depth 1000) มีพื้นมืด กล่อง ข้อความ คำถามตัวหนา (ถ้ามี) ปุ่ม NO/YES (ข้อความเกิน 7 ตัวลดขนาดตัวอักษร) และปุ่ม X ถ้า closable กดปุ่มใดก็ทำลาย Container ก่อนแล้วเรียกฟังก์ชันที่กำหนด
tealPopup(scene, title, onClose)ป๊อปอัปสีฟ้า (Hint/Profile) ขนาด 452×388 พื้นมืดกดแล้วปิด กรอบรับคลิกกันทะลุ ปุ่มปิด และป้ายหัวเรื่อง
card(...)กล่องขาวขอบสีมีเงา
statRows(scene, pet, top)วาดค่าสถานะ 4 แถว (ห่างกัน 30.7 พิกเซล) แต่ละแถว = ไอคอน + pillMeter + ตัวเลข
