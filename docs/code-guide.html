index.html81 บรรทัด

หน้าเว็บที่เปิดในเบราว์เซอร์ ทำหน้าที่ 3 อย่าง:

  • เลย์เอาต์แนวนอน #layout: กรอบเกม #app (มี #game-container ที่ Phaser ใส่ canvas ลงไป) อยู่ซ้าย และแผงแชทอยู่ขวา
  • มีโครง HTML ของแผงแชท #chat-screen: รูปสัตว์ ชื่อ ร่าง/ขั้น, รายการข้อความ #cs-log, แผงประโยคลัดและอีโมจิ, ช่องพิมพ์ และปุ่มไมค์ หน้าแชททำเป็น HTML เพราะพิมพ์ภาษาไทยและใช้ไมค์ได้ง่ายกว่าทำใน canvas
  • โหลด Phaser จาก CDN แล้วโหลดไฟล์ JS ทั้งหมดตามลำดับ รวมถึง assets/sprites/manifest.js (รายการรูปตัวละครที่สคริปต์สร้างไว้)

css/style.css243 บรรทัด

  • กำหนดสีตามดีไซน์เป็นตัวแปร เช่น --olive, --olive-mid, --olive-light
  • #layout วางเกม (สัดส่วน 960:600 = 16:10) กับแชท (กว้าง --chat-w = 330px) คู่กัน เว้นขอบและช่องว่าง 16px (--gap)
  • --game-h คำนวณความสูงเกมให้ใหญ่ที่สุดที่ยังพอดีจอหลังหักแชทออก แผงแชทสูงเท่าเกมเสมอ
  • จอแคบกว่า 760px (มือถือ) จะเรียงเกมไว้บน แชทไว้ล่างแทน
  • .disabled ทำให้แผงแชทจางและพิมพ์ไม่ได้ตอนยังไม่เข้าหน้าเลี้ยง
  • สไตล์ฟองแชท: ข้อความสัตว์เป็นสีมะกอกอ่อนอยู่ซ้าย ข้อความผู้เล่นเป็นสีขาวอยู่ขวา ปุ่มไมค์จะกลายเป็นปุ่มส่งเมื่อมีข้อความ (.has-text) และกะพริบแดงขณะฟังเสียง (.listening)

คลาส PetState แทนสัตว์เลี้ยง 1 ตัว และเป็นข้อมูลที่ทุกระบบอ่าน

ฟังก์ชัน / ข้อมูลหน้าที่
statsค่าสถานะ 4 ตัว (0–100)
careWindow"หน้าต่างพฤติกรรม" สะสมแต้มการดูแลแต่ละหมวด (feed / play / care / rest) จำนวนครั้งที่คุยกัน (chat) เวลาที่ถูกละเลย และค่าเฉลี่ยความเป็นอยู่ ตั้งแต่วิวัฒนาการครั้งล่าสุด (ข้อมูลหลักของ EvolutionAI)
migrate()เรียกตอนโหลดเซฟ: แปลงชื่อสายและร่างที่ปลดล็อกจากเวอร์ชันเก่าให้เป็นสายใหม่ เซฟเดิมจึงเล่นต่อได้

onChat()เมื่อคุยหรือลูบตัว: นับเป็นการโต้ตอบ (หายเหงา) เพิ่มความผูกพันและความสุขเล็กน้อย และนับ careWindow.chat (ใช้ปลดล็อกสายลับ Leader)

EmotionAI.js — 1.1 AI Emotion & Needs59 บรรทัด

evaluate(pet) ให้คะแนนแต่ละอารมณ์จากค่าสถานะ แล้วเลือกอารมณ์ที่คะแนนสูงสุด:

sick   = health < 35    ? (35 - health)    × 3   : 0
hungry = fullness < 40  ? (40 - fullness)  × 2.5 : 0
tired  = energy < 30    ? (30 - energy)    × 2.5 : 0
lonely = ไม่มีใครโต้ตอบ > 45 วิ และ happiness < 65 ? เวลาที่เหงา + (65 - happiness) : 0
sad    = happiness < 35 ? (35 - happiness) × 2   : 0
happy  = ค่าเฉลี่ย > 70 ? ค่าเฉลี่ย - 55 : 0
normal = 12   // ค่าตั้งต้น ถ้าไม่มีอะไรเด่นจะเป็น "Fine"

ผลลัพธ์มี label, emoji, anim (ชื่อแอนิเมชัน), need (สิ่งที่ต้องการ) และ intensity (ความรุนแรง 0–1) GameScene เอา anim ไปเล่นท่าทาง เช่น hop = กระโดด, sway = ส่ายตัว, look = หันมองหา, shiver = ตัวสั่น ส่วน callout() คือประโยคที่สัตว์ "เรียก" ผู้เล่นเองเมื่อต้องการบางอย่าง

คืนค่าเหตุผล (reason), สัดส่วนแต่ละหมวด (shares) และจำนวนครั้งที่คุย (chats) เพื่อแสดงในหน้า Report และฉากวิวัฒนาการ ส่วน lowData ใช้บอกว่าข้อมูลยังน้อยเกินจะทำนาย ค่าเกณฑ์ทั้งหมดปรับได้ที่ CFG ด้านบนของไฟล์ (เช่น leaderMinChats)

CareAdvisor.js — 1.3 Smart Care Recommendation64 บรรทัด

urgency(pet) คำนวณคะแนนความเร่งด่วนของแต่ละความต้องการ ใช้การยกกำลังสอง ค่าที่ต่ำมากจึงเร่งด่วนกว่าค่าที่ต่ำนิดหน่อยอย่างชัดเจน:

คะแนน = ((100 - ค่า) / 100)² × 100 × น้ำหนัก     // น้ำหนัก: feed 1.25, care 1.3, play 1.0, rest 1.1
play  += เวลาที่เหงา × 0.4                        // ยิ่งไม่มีใครเล่นด้วยนาน ยิ่งอยากเล่น
ถ้า energy < 15 → คะแนน play × 0.2                // เหนื่อยเกินไป ให้พักก่อน

recommend(pet, emotion) เลือกอันดับ 1 แล้วสร้างข้อความแนะนำ (แบบเบาเมื่อคะแนนต่ำกว่า 30, แบบชัดเจนเมื่อสูงกว่านั้น) itemFor() บอกว่าควรใช้ไอเทมไหน เช่น สุขภาพต่ำกว่า 30 แนะนำ Medicine แทน Bath GameScene เอาผลนี้ไปแสดงในแถบ 💡 และไฮไลต์แท็บ/ไอเทมเป็นสีเหลือง

PetChatbot.js — 1.4 Smart Pet Chatbot131 บรรทัด

แชทบอทแบบกฎ (rule-based) ทำงานออฟไลน์ ไม่ต้องใช้ API มี 2 ขั้นตอน:

  1. detectIntent(text) หาคำสำคัญในข้อความตามรายการ INTENTS เช่น "เป็นอะไร" → status, "หิว/ข้าว" → hunger, "รัก" → love (intent ที่อยู่ก่อนในรายการจะถูกตรวจก่อน)
  2. replyFor(intent, ctx) เลือกคำตอบจาก intent + อารมณ์ + ค่าสถานะ + ชนิดสัตว์ + ระดับความผูกพัน
ผู้เล่น: "เป็นอะไรหรือเปล่า?"  → intent = status, อารมณ์ = hungry
น้อง:    "เราหิวแล้ว ขออาหารหน่อยได้ไหม?"

กฎพิเศษ: ถ้าหลับอยู่จะตอบแบบละเมอ ถ้ามีความต้องการเร่งด่วน (หิว ป่วย เหงา) น้องจะพูดถึงเรื่องนั้นก่อน ถ้าความผูกพันสูง คำตอบ "รักนะ" จะอบอุ่นขึ้น reply() ยังเติมเสียงตามชนิดสัตว์ (โฮ่ง! / เมี้ยว~) และ intent "evolve" ดึงผลทำนายจาก EvolutionAI มาตอบด้วย
