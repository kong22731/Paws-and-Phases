## 3. วิธีติดตั้งและรัน

### แบบที่ 1: เล่นออนไลน์ (ง่ายที่สุด)
1. เปิดลิงก์ https://kong22731.github.io/Paws-and-Phases/ ด้วย Chrome หรือ Edge
2. คลิกหน้าเกม 1 ครั้งเพื่อเปิดเสียง แล้วกด **START** เพื่อเริ่มเลี้ยง
3. ถ้าจะเล่นด้วยมือ กดปุ่ม ✋ ที่หน้าปก แล้วกด **Allow** ให้เบราว์เซอร์ใช้กล้อง

### แบบที่ 2: รันในเครื่องตัวเอง
**สิ่งที่ต้องมี:** Google Chrome หรือ Microsoft Edge และอินเทอร์เน็ต (เพื่อโหลด Phaser ฟอนต์ และโมเดลจดจำมือ) · ไม่ต้องติดตั้ง Node.js หรือ npm

1. **ดาวน์โหลดโค้ด:** เปิดหน้า Source Code → กดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์ (หรือ Clone ด้วย GitHub Desktop)
2. **เปิดเซิร์ฟเวอร์ในเครื่อง** เลือกวิธีใดวิธีหนึ่ง:
   - **Windows:** ดับเบิลคลิกไฟล์ **`start.bat`** ในโฟลเดอร์เกม เบราว์เซอร์จะเปิด http://localhost:8080 ให้เอง
   - **VS Code (ทุกระบบ):** ติดตั้งส่วนเสริม *Live Server* → คลิกขวา `index.html` → **Open with Live Server**
   - **Mac / Linux:** เปิด Terminal ในโฟลเดอร์เกม พิมพ์ `python3 -m http.server 8080` แล้วเปิด http://localhost:8080
3. เกมจะโหลดแล้วขึ้นหน้าปก กด **START** เพื่อเริ่มเล่น หรือ **Continue** เพื่อเล่นต่อจากไฟล์ที่บันทึกไว้

> ⚠️ **ห้ามดับเบิลคลิก `index.html` ตรง ๆ** เพราะเบราว์เซอร์จะไม่ให้โหลดรูปและใช้กล้อง ต้องเปิดผ่านเซิร์ฟเวอร์ตามขั้นที่ 2
>
> 💾 เซฟเกมเก็บในเบราว์เซอร์ของเครื่องที่เล่น (localStorage) แยกตามเบราว์เซอร์และลิงก์

## 5. วิธีตั้งค่า API Key

**เกมนี้ไม่ต้องตั้งค่า API Key** ดาวน์โหลดแล้วเปิดเล่นได้ทันที

| ส่วน | ทำไมไม่ต้องใช้ API Key |
|---|---|
| AI ทั้ง 4 ตัว (รวมแชทบอท) | เขียนเป็นระบบให้คะแนนและกฎในโค้ดของเกมเอง ทำงานในเครื่องผู้เล่น ไม่ได้เรียก ChatGPT, Claude หรือบริการ AI ภายนอก |
| จดจำท่ามือ (MediaPipe) | โหลดไลบรารีและโมเดลจาก CDN สาธารณะของ Google ใช้ฟรี ไม่ต้องลงทะเบียน · ภาพกล้องประมวลผลในเครื่องเท่านั้น |
| รู้จำเสียงพูดภาษาไทย | ใช้ Web Speech API ที่มีในเบราว์เซอร์ Chrome / Edge |
| Phaser และ Google Fonts | โหลดจาก CDN สาธารณะ ไม่ต้องใช้ key |

### กรณีพัฒนาต่อแล้วต้องใช้ API Key (เผื่ออนาคต)
ถ้าวันหน้าเปลี่ยนแชทบอทไปใช้ AI ออนไลน์ (เช่น Claude API หรือ OpenAI API) ให้ทำดังนี้:
1. **สมัครและสร้าง API Key** จากเว็บไซต์ผู้ให้บริการ (เช่น console.anthropic.com หรือ platform.openai.com)
2. **ห้ามใส่ API Key ในไฟล์ JavaScript ของเกม** เพราะเกมเป็นเว็บที่ทุกคนเปิดดูโค้ดได้ ใครก็คัดลอก key ไปใช้ได้ และอาจถูกเรียกเก็บเงิน
3. **ทำเซิร์ฟเวอร์ตัวกลาง (backend)** เช่น Node.js หรือ Serverless Function ให้เกมส่งข้อความไปที่เซิร์ฟเวอร์ แล้วเซิร์ฟเวอร์เป็นผู้เรียก API ด้วย key
4. **เก็บ key ในไฟล์ `.env`** บนเซิร์ฟเวอร์ เช่น `ANTHROPIC_API_KEY=xxxxx` แล้วเพิ่ม `.env` ลงใน `.gitignore` เพื่อไม่ให้ key ถูกส่งขึ้น GitHub
5. ถ้าเผลอส่ง key ขึ้น GitHub ให้ **ยกเลิก key นั้นทันที** ที่เว็บผู้ให้บริการ แล้วสร้างใหม่

### วิธีเล่นโดยย่อ
- **ค่าสถานะ 4 ค่า** (อิ่ม · สะอาด · สุข · พลัง) ลดลงตามเวลา ดูแลผ่านเมนู **Grooming** (Feed / Play / Care / Rest)
- **1 วัน = 3 นาที** (เปลี่ยนเป็น 3 / 5 / 7 / 10 นาที และเร่งเวลา x1 – x10 ได้ที่เมนู) หมดวันกด **NEXT DAY** แล้ว AI ตัดสินการเติบโตจากการเลี้ยงทั้งวัน
- **Social (แถบสีชมพู):** คุยแชท +3 ต่อข้อความ · ท่า 👍 +2 · ทั้งวันไม่คุยเลย −8
- **บันทึกเกม:** สัตว์ตัวใหม่บันทึกลงไฟล์ว่างอัตโนมัติ (มี 3 ไฟล์) และบันทึกเองทุก 5 วินาที

### เงื่อนไขสายวิวัฒนาการ
- **ร่าง 1 → 2:** ผ่านเงื่อนไขสายไหน ได้ร่าง 2 ของสายนั้น
- **ร่าง 2–4:** ผ่านเป้าสายเดิม → ขึ้น 1 ร่าง · เกือบถึง → คงร่าง · พลาดติดกัน 2 วัน (ร่าง 2–3) หรือ 3 วัน (ร่าง 4) → ถอย 1 ร่าง
- **ร่าง 5:** ร่างคงที่ ปลดล็อกชื่อสายใน Evolution Book และกด **Rebirth** เพื่อเริ่มใหม่ได้
- ร่าง 1–2 ใช้เกณฑ์ง่ายกว่า ตารางด้านล่างคือเกณฑ์ปกติ (ร่าง 3 ขึ้นไป)

| สาย | เงื่อนไขต่อวัน | ร่าง 2 → 5 |
|---|---|---|
| 👽 Neglect | แต้มรวม < 15 (แทบไม่ดูแล) | Neglected Stalker → Emaciated Mutant → Hybrid Alien-Beast → Apex Alien Entity |
| 🎩 Leader (สายลับ) | สมดุลแบบ Royal + คุยกัน ≥ 8 ครั้งต่อวัน | Agent Trainee → Elite Strategist → Prominent Statesman → Prime Minister Icon |
| 👑 Royal | ทุกด้าน 10–45% และแต้มรวม ≥ 40 | Dapper Noble → Royal Heir → Regal Aristocrat → Sovereign Monarch |
| 💤 Sleepy | Rest ≥ 50% และ Feed / Play / Care แต่ละด้าน ≤ 20% | Drowsy Hatchling → Coiling Cub → Mystic Serpent-Form → Celestial Dragon Form |
| 🐷 Gluttony | Feed มากที่สุดและ ≥ 45% · Play, Care ≤ 20% * | Chubby Eater → Gluttonous Form → Insatiable Beast → Demon Lord of Gluttony |
| 🧼 Self-Care | Care มากที่สุดและ ≥ 45% · Play, Feed ≤ 20% * | Hygiene Learner → Bubble-Kissed Form → Lathering Form → Pure Soap Sovereign |
| 🏋️ Playful | Play มากที่สุดและ ≥ 45% · Care, Feed ≤ 20% * | Energetic Rookie → Fledgling Brawler → Powerhouse Beast → Apex Muscle Icon |

\* 3 สายนี้คิด % จาก Feed + Play + Care เท่านั้น ไม่นับ Rest
